# Logo export sizes

## Symbol
- 16x16 (favicon small)
- 32x32 (favicon standard)
- 48x48 (favicon)
- 64x64 (app icon small)
- 128x128 (app icon)
- 256x256 (app icon)
- 512x512 (high-res app icon)

## Wordmark
- 220x48 (desktop header)
- 180x40 (mobile header)
- 120x32 (compact)

## Favicon
- favicon.ico (multi-size: 16,32,48)
- favicon.svg (scalable)

See SVG source files in this directory. For production, generate PNGs at these sizes from the source SVGs.
